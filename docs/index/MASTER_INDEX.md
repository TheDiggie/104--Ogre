# Master index - the one door

Every topic file, root file, sub-index and rule, one line each. Every
destination is listed directly; never chain three files to reach a fact.

## Topic files (docs/systems/)

- docs/systems/wire-format.md - the places where the obvious reading of a
  protocol field is wrong: ObjectFlags bytes, ObjectID length, message ids.
- docs/systems/godot-ui.md - Godot traps this client hit: rectless
  parents, sibling draw order, subscribe-don't-poll, init ordering.
- docs/systems/harness.md - SceneShot, the headless play harness: how to
  run it, the invariant tour, and the two harness bugs that hid real ones.
- docs/systems/fake-server.md - the test server, what it fixtures, and why
  a missing fixture reads as a missing feature.
- docs/systems/delivery.md - how work reaches Ashton's machine (git
  bundle, not push) and the six unsigned commits.
- docs/systems/mobile-client.md - the Godot phone client: its panels, the
  hotbar store, the deliberate gaps.

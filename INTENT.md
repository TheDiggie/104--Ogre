# Intent

PURPOSE: The standing intent behind this project - what the work is for -
  so that a session which has lost its history can still tell whether a
  change serves the goal or merely compiles.
INTENT: work that is technically correct and beside the point is the most
  expensive kind, and a written intent is what catches it.

Search keys: intent, goal, why, purpose of the port.

## The goal
Tags: design | Make Meridian 59 Server 104 playable on a phone, faithfully

Not a companion app, not a viewer: the game, playable, on a touch screen.
Faithful to the reference client wherever a phone can be faithful, and
deliberately different - with the reason written down - wherever it
cannot.
